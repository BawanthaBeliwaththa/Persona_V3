Persona V3 Architecture Overview

Persona V3 is an enterprise-grade LinkedIn profile extraction, search, and candidate ranking system built with Flask, Playwright (Chromium), Pydantic, and Server-Sent Events (SSE).

⚡
Flask & Async Loop

Uses a multi-threaded Flask core with a dedicated background asyncio event loop to run Playwright browser operations smoothly without blocking HTTP endpoints.

🗂️
Task Bucket Queue

Automated rate-limited queue manager. Tasks are processed sequentially with customizable rest periods (default: 30s) to prevent LinkedIn account rate limits.

📡
Real-Time SSE Stream

Server-Sent Events (SSE) stream live log events, queue statuses, and worker rest timers directly to admin and client UI dashboards without polling.

How to Install and Run Persona V3 Locally

Follow these 5 exact steps to set up and run Persona V3 on your development computer:

STEP 1: Clone Repository

Open your terminal or command prompt and clone the Persona V3 repository from GitHub:

git clone https://github.com/BawanthaBeliwaththa/Persona_V3.git
cd Persona_V3
STEP 2: Create Python Virtual Environment

Create and activate an isolated Python 3.10+ virtual environment:

# On Windows (PowerShell/CMD):
python -m venv venv
venv\Scripts\activate

# On Linux / macOS:
python3 -m venv venv
source venv/bin/activate
STEP 3: Install Required Dependencies

Install all required Python packages listed in req.txt:

pip install --upgrade pip
pip install -r req.txt
STEP 4: Install Playwright Chromium Browser

Download and install Playwright's headless Chromium browser binary:

playwright install chromium
STEP 5: Launch Persona V3 Web Application

Start the Flask development server:

python app.py

Open your browser and navigate to:

  • Client Portal: http://localhost:5000/
  • Admin Portal: http://localhost:5000/admin

How to Use the Portals & Task Bucket

🛠️
1. Admin Portal (`/admin`)
  1. Initialize Scraper: Enter session name, select Headless (Off for local setup, On for VPS), and click Initialize Browser.
  2. Authenticate: Enter your LinkedIn credentials and click Login (or authenticate manually if security verification appears).
  3. Task Bucket Management: Navigate to the Task Bucket tab. Add keyword searches or LinkedIn URLs. Set the rest timer (e.g. 30s) and click Resume.
  4. Export Master Data: Download complete scraped profiles in JSON or CSV format.
👤
2. Client Portal (`/`)
  1. Direct Search: Enter a LinkedIn username (e.g., beliwaththa) or full profile URL and click Search & Extract All.
  2. Reference Tracking: Each search generates a unique Reference Code (e.g. REF-8F42A1). Use this code anytime to reload cached results.
  3. Bulk CSV/JSON Import: Upload a list of queries or URLs in CSV or JSON format to queue multiple extractions.
  4. PDF Report Export: Click Export Full Text as PDF to print candidate profile reports.

How to Deploy to VPS Without Terminal (Coolify / PaaS)

Deploy Persona V3 using a browser UI without typing terminal SSH commands:

Step 1: Launch VPS with Coolify

Create an Ubuntu VPS on DigitalOcean or Hetzner using the 1-Click Coolify marketplace image.

Step 2: Connect GitHub Repository

Open https://YOUR_VPS_IP:8000, go to Sources → GitHub, and select BawanthaBeliwaththa/Persona_V3.

Step 3: Environment Configuration & Deploy

Add environment variables (PYTHONUNBUFFERED=1), click Deploy. Coolify builds your container using the project Dockerfile automatically.

Dockerfile (Included in Repository Root) 
FROM mcr.microsoft.com/playwright/python:v1.45.0-noble

WORKDIR /app

COPY req.txt .
RUN pip install --no-cache-dir -r req.txt
RUN playwright install chromium

COPY . .

EXPOSE 5000
CMD ["gunicorn", "--workers=2", "--threads=4", "--bind=0.0.0.0:5000", "app:app"]

How to Deploy to VPS Using SSH Terminal

Follow these terminal commands on Ubuntu 22.04 / 24.04 LTS to set up Persona V3 manually:

Terminal Commands (SSH & System Setup) 
# 1. Connect & install OS packages
ssh root@YOUR_VPS_IP
sudo apt update && sudo apt upgrade -y
sudo apt install -y python3 python3-pip python3-venv git curl nginx

# 2. Clone Persona V3 repo & setup virtual environment
cd /var/www
git clone https://github.com/BawanthaBeliwaththa/Persona_V3.git
cd Persona_V3
python3 -m venv venv
source venv/bin/activate
pip install -r req.txt

# 3. Install Playwright browser & Linux system OS dependencies
playwright install --with-deps chromium

Configure Systemd Background Service

Terminal: sudo nano /etc/systemd/system/personav3.service 
[Unit]
Description=Persona V3 Flask Service
After=network.target

[Service]
User=root
WorkingDirectory=/var/www/Persona_V3
Environment="PATH=/var/www/Persona_V3/venv/bin"
Environment="PYTHONUNBUFFERED=1"
ExecStart=/var/www/Persona_V3/venv/bin/gunicorn --workers 2 --threads 4 --bind 127.0.0.1:5000 app:app
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
sudo systemctl daemon-reload
sudo systemctl start personav3
sudo systemctl enable personav3

How External Frontend Teams Connect to Persona V3 API

The separate frontend development team can connect their UI (React, Next.js, Vue, Mobile) directly to Persona V3 endpoints.

Method Endpoint Route Payload / Description
POST /api/scraper/init {"headless": true, "session_name": "default"} — Init browser
POST /api/client/scrape {"name": "https://linkedin.com/in/username"} — Extract profile
GET /api/events EventSource stream for live SSE status events

JavaScript Integration Snippet

api.js (Frontend Service) 
const API_BASE_URL = "https://api.yourdomain.com";

// Execute Persona V3 extraction
async function extractProfile(urlOrName) {
    const res = await fetch(`${API_BASE_URL}/api/client/scrape`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ name: urlOrName })
    });
    return await res.json();
}
