# Security Policy (SP) - Persona Project

## 1. Purpose
This policy outlines the acceptable use, data protection standards, and operational security requirements for running the Persona LinkedIn Profile Intelligence Platform.

## 2. Scope
This policy applies to all personnel deploying, operating, or accessing the Persona system, as well as the data generated by it.

## 3. Acceptable Use
- The system shall only be used for legitimate business purposes (e.g., recruitment, B2B lead generation).
- Operators must not use the system to harass, spam, or mass-message users on LinkedIn.

## 4. Data Protection Standards
- All exported data (JSON/CSV) must be treated as Confidential Business Information.
- Profile data must not be sold or distributed to unauthorized third parties.
- If data subjects request deletion (GDPR/CCPA compliance), their records must be manually purged from `all_scraped_profiles.json` and the CSV mirror.

## 5. Incident Response
If the host server is compromised or unauthorized access to the Admin UI is detected:
1. Immediately shut down the Flask server.
2. Delete the `browser_data/` directory to invalidate the hijacked LinkedIn session cookies.
3. Change the password for the LinkedIn account used by the scraper.
4. Implement proper network firewalls and proxy authentication before restarting the service.
