1. How It Works Under the Hood Architecture

Persona V3 operates as an independent, headless microservice inside the SYS directory. All frontend interactions are managed directly in Zoho CRM / Zoho Flow, which communicates with Persona via asynchronous HTTP REST webhooks.

1

Zoho CRM Triggers Webhook

When a recruiter clicks "Enrich Profile" in Zoho CRM, a Deluge script calls POST /api/client/scrape with candidate name or LinkedIn URL.

2

Instant 202 Accepted Acknowledgement

FastAPI acknowledges the request immediately with an HTTP 202 Accepted and a tracking UUID reference number, avoiding Zoho Deluge timeout limits.

3

Task Bucket Worker Consumes Task

The continuous background consumer (worker.py) pops the task, controls the Playwright Chromium browser, expands text, extracts all DOM sections, and captures contact details.

4

7-Stage Data Sanitization & ML Scoring

The raw profile is cleansed of UI noise (footer links, language selectors) and scored across 15 features before being stored in exports/all_scraped_profiles.json.

5

Zoho Scheduled Polling Auto-Populates CRM Record

A Zoho Scheduled Function polls GET /api/client/scrape-status and populates candidate fields (Headline, Experience, Education, Skills) upon completion.

How Persona navigates, expands, and extracts deep profile sections from LinkedIn:

About Accordion expansion + sanitization Full candidate bio & summary description

Intelligent Search Modes (Username, Name, Company & Direct URL)

The POST /api/client/scrape endpoint accepts multiple search formats:

Mode Example Payload How Persona Resolves It
Direct Username / Handle {"username": "beliwaththa"} or {"name": "beliwaththa"} Directly checks https://www.linkedin.com/in/beliwaththa. Zero ambiguity, fast extraction.
First & Last Name {"first_name": "Bawantha", "last_name": "Beliwaththa"} Searches LinkedIn people directory and extracts the top verified matching profile.
Name + Target Company {"name": "Bawantha Beliwaththa", "company": "TechCorp"} Filters search results strictly for candidates working at the designated company.
Direct Profile URL {"profile_url": "https://www.linkedin.com/in/beliwaththa"} Direct extraction of all sections, contact info, and premium status.

4. The 7-Stage Data Sanitization Sieve cleaner.py

LinkedIn single-page applications embed UI garbage (navigation headers, footer links, language pickers) alongside user data. The cleaner.py pipeline strips all noise:

Stage Target Function Sanitization Action
1 _clean_value() Normalizes "none", "null", "n/a", or whitespace to Python None.
2 _clean_about() Truncates footer disclaimers ("Accessibility", "Talent Solutions") and trailing "...more".
3 _clean_experience_list() Validates job titles/companies, removes button artifacts, deduplicates positions.
4 _clean_education_list() Normalizes university and degree names; purges accidental skill tags.
5 _clean_certification_list() Strips "Show credential" buttons; isolates issuing organization and credential URLs.
6 _clean_languages_list() Validates against real human language dictionary to eliminate UI language selector drops.
7 _clean_skills_list() Standardizes skill dictionaries and performs case-insensitive deduplication.

5. Task Bucket Queue & Anti-Ban Protection worker.py

LinkedIn aggressively tracks multi-tab concurrent browsing. Persona enforces a strict Single-Worker FIFO Invariant with randomized rest delays to safeguard accounts:

Safeguard Implementation Formula / Detail Purpose
Single Consumer 1 Worker Loop on native asyncio Eliminates simultaneous multi-tab scraping bans
Randomized Jitter T = random(rest_seconds, rest_seconds + 15) Mimics natural human browsing variability
Name Caching Persistent name_cache.json Avoids redundant repeated scraping of the same person

7. Zoho CRM Deluge Integration Manual Deluge Code

Deploy these two Deluge scripts into Zoho CRM to enable single-click candidate enrichment and background polling:

Script 1: Trigger Button (Candidate Module → Custom Button)

ZOHO DELUGE • Candidate Trigger 
candidateId = targetCandidateId.toLong();
candidateRecord = zoho.crm.getRecordById("Candidates", candidateId);

candidateName = candidateRecord.get("Full_Name");
linkedinUrl = candidateRecord.get("LinkedIn_URL");

serverUrl = "http://your-server-ip:8000/api/client/scrape";

payload = Map();
if (linkedinUrl != null && linkedinUrl != "") {
    payload.put("profile_url", linkedinUrl);
} else {
    payload.put("name", candidateName);
}

headers = Map();
headers.put("Content-Type", "application/json");

response = invokeurl [
    url: serverUrl,
    type: POST,
    parameters: payload.toString(),
    headers: headers
];

if (response.get("success") == true) {
    refNumber = response.get("reference_number");
    updateMap = Map();
    updateMap.put("Enrichment_Status", "In Progress");
    updateMap.put("Persona_Reference", refNumber);
    zoho.crm.updateRecord("Candidates", candidateId, updateMap);
    return "Task queued in Persona bucket. Reference: " + refNumber;
} else {
    return "Error: " + response.get("error");
}

Script 2: Scheduled Polling Function (Settings → Scheduled Functions)

ZOHO DELUGE • Scheduled Polling Sync 
inProgressCandidates = zoho.crm.searchRecords("Candidates", "(Enrichment_Status:equals:In Progress)");

for each candidate in inProgressCandidates {
    candidateId = candidate.get("id");
    refNumber = candidate.get("Persona_Reference");
    
    if (refNumber != null && refNumber != "") {
        statusUrl = "http://your-server-ip:8000/api/client/scrape-status?task_id=" + refNumber;
        statusResponse = invokeurl [ url: statusUrl, type: GET ];
        
        if (statusResponse.get("status") == "completed") {
            profiles = statusResponse.get("profiles");
            if (profiles.size() > 0) {
                p = profiles.get(0);
                updateData = Map();
                updateData.put("Enrichment_Status", "Completed");
                updateData.put("Current_Job", p.get("headline"));
                updateData.put("Location", p.get("location"));
                updateData.put("Summary", p.get("about"));
                updateData.put("LinkedIn_URL", p.get("profile_url"));
                zoho.crm.updateRecord("Candidates", candidateId, updateData);
            }
        }
    }
}
